# Written by hand from the ESP-AT command reference extract (source commit b2921f8f), not recorded from a module.
# AT+CWMODE? is answered only after its timeout. The late info line is dropped, and the late OK is the late final. The drain's AT is then
# answered with its own OK, which ends the drain. AT+CWQAP is sent at once after the drain, and its OK ends it.
> AT+CWMODE?
@ 2000
> AT
< +CWMODE:1
<
< OK
< AT
< OK
> AT+CWQAP
< AT+CWQAP
< OK
