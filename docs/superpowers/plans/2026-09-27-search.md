# Documentation Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Finish instant navigation, accessible themes, Utilities prioritization and static hybrid semantic search.

**Architecture:** Keep synchronous MiniSearch and add a lazy query worker consuming build-time versioned embeddings. Source anchors share the existing reveal contract.

**Tech Stack:** Vue 3, TypeScript, MiniSearch, Transformers.js 3.8.1, Node 22, Cache Storage, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-search-design.md`

## Global Constraints

- English code/docs/UI; Russian user conversation. Explicit types, K&R braces, no new underscore-prefixed identifiers.
- Preserve dirty worktree changes. No worker commits or pushes. Root handles final integration.
- Model: `Xenova/all-MiniLM-L6-v2`, revision `751bff37182d3f1213fa05d7196b954e230abad9`, q8, mean pooling, normalized 384-dimensional vectors.
- Lexical results must work without semantic assets, storage, network or WebAssembly.
- Use existing `SearchTarget` fields: path, tab, terms, snippet, headingOnly.
- Review correction: add optional API source scope to the chunk/target contract. Preserve token-origin spans while flattening API data; carry the first chunk token's stable member scope into the rendered API. Keep sixty-word chunks rather than multiplying embeddings per member. Restrict a scoped reveal to that member instead of falling back to the first generic token on the page. Bump chunking/schema configuration and regenerate artifacts.

## Review Focus

1. Corrupt or old artifacts cannot mix with current pages (Task 2/3 tests).
2. Rapid queries and failed workers cannot overwrite newer results or block baseline search (Task 3 tests).
3. Denied browser storage cannot prevent theme/search initialization (Task 1/3 tests).
4. Semantic paraphrases must reveal actual chunk text and correct tab (Task 3 browser test).
5. CI builds both branches together, and production worker/WASM paths work below `/VHAL/` (Task 4 smoke).
